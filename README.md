# 🌾 ग्राम मेड़ा (Merha) - आधिकारिक ग्राम पोर्टल

एक व्यापक और इंटरैक्टिव डिजिटल पोर्टल, जिसे **ग्राम मेड़ा** (कटोरिया, बांका, बिहार) की समृद्ध विरासत, संस्कृति, पर्यटन स्थल, स्थानीय सेवाओं और विकास कार्यों को एक मंच पर प्रस्तुत करने के लिए विकसित किया गया है।

---

## 📌 मुख्य विशेषताएं (Key Features)

* **📖 गांव का परिचय एवं इतिहास:** गांव का समृद्ध इतिहास, भौगोलिक स्थिति, संस्कृति और पारंपरिक पहचान।
* **📍 लोकेशन व दिशा-निर्देश (Interactive Map):** गूगल मैप्स और सटीक जीपीएस लोकेशन के माध्यम से गांव तक पहुंचने का सुगम मार्ग।
* **🖼️ डिजिटल फोटो एवं वीडियो गैलरी:** 
  * गांव के प्राकृतिक दृश्य, तालाब और खेत-खलिहान
  * ऐतिहासिक एवं धार्मिक स्थल
  * सांस्कृतिक उत्सव, मेले और सामाजिक कार्यक्रम
* **📚 शिक्षा एवं कोचिंग (Education & Tuition Hub):**
  * स्थानीय सरकारी स्कूल, प्राथमिक विद्यालय एवं पुस्तकालय
  * कोचिंग/ट्यूशन सेंटर, शिक्षकों के विवरण और अध्ययन संसाधन
* **🏛️ महत्वपूर्ण संस्थान एवं सार्वजनिक सेवाएं:**
  * पंचायत भवन, डाकघर और स्वास्थ्य केंद्र की जानकारी
  * राशन वितरण, कृषि सेवा केंद्र और आपातकालीन संपर्क सूत्र
* **📶 डिजिटल कम्युनिटी & वाई-फाई पोर्टल:** गांव के डिजिटल सेवा केंद्रों और कनेक्टिविटी से संबंधित अद्यतन विवरण।

## 📂 प्रोजेक्ट संरचना (Folder Structure)

```text
village-portal/
├── index.html              # मुख्य होमपेज (Home Page)
├── about.html              # गांव का परिचय एवं इतिहास
├── gallery.html            # फोटो एवं वीडियो गैलरी
├── education.html          # स्कूल, कॉलेज एवं ट्यूशन जानकारी
├── location.html           # मानचित्र, दिशा-निर्देश एवं रूट गाइड
├── services.html           # ग्राम पंचायत, स्वास्थ्य व आवश्यक सेवाएं
├── assets/
│   ├── css/                # स्टाइलशीट्स (Design & Layout)
│   ├── js/                 # इंटरैक्टिव स्क्रिप्ट्स (Map API, Gallery Lightbox)
│   └── images/             # गांव के फोटोग्राफ्स एवं आइकन्स
└── README.md               # प्रोजेक्ट प्रलेखन (Documentation)
```

## 🚀 इंस्टॉलेशन एवं रन करने का तरीका (Getting Started)

1. **रिपॉजिटरी को क्लोन करें:**
   ```bash
   git clone https://github.com/your-username/village-merha-portal.git
   ```
2. **प्रोजेक्ट फ़ोल्डर में जाएं:**
   ```bash
   cd village-merha-portal
   ```
3. **स्थानीय ब्राउज़र में चलाएं:**
   * `index.html` फ़ाइल को किसी भी आधुनिक वेब ब्राउज़र (Chrome, Edge, Brave आदि) में खोलें।
   * या फिर Live Server (VS Code Extension) का उपयोग करें।
